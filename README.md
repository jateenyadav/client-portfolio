# Tanishka Sen - Portfolio

A colorful, animated single-page portfolio for **Tanishka Sen**, Social Media & Performance Marketing Executive (Dubai, UAE). Built with plain HTML, CSS and vanilla JavaScript - no build step required.

## Highlights

- Animated gradient background blobs, scroll progress bar, and glassy sticky navbar
- Hero with typewriter role animation, floating result badges and mouse parallax portrait
- Scroll-reveal animations, animated skill bars, and count-up result stats
- Sections: About, Skills, Experience & Education timeline, Results (with real Instagram insight screenshots), Projects (case studies), Designs gallery, Tools, Certifications, Contact
- Fully responsive with a mobile slide-in menu and reduced-motion support

All content and imagery were extracted from Tanishka's CV and marketing portfolio PDFs.

## Run it

Just open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Structure

```
index.html      # markup
styles.css      # styling + animations
script.js       # interactivity (nav, typewriter, reveals, counters)
assets/img/     # profile photo, analytics screenshots, design samples, certificate
```
