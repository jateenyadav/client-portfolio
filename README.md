# Tanishka Sen — Marketing Portfolio

A colorful, animated, single-page portfolio built for a client, **Tanishka Sen** — a Marketing Executive based in Dubai, UAE. Built with plain **HTML, CSS, and vanilla JavaScript** — no framework, no build step.

**Live site:** https://jateenyadav.github.io/tanishka-portfolio/

> A client project: full-funnel marketing portfolio designed and developed end-to-end.

## Highlights

- **Two themes** — cinematic dark mode + a bright pink light theme, with a toggle that remembers your choice (`localStorage`)
- **Typographic hero** — oversized animated gradient wordmark with floating result badges and a typewriter role line
- **Scroll-driven reveals** — content fades and rises into view one element at a time
- **Services roadmap** — a vertical timeline with numbered gradient nodes and a scroll-linked progress line
- **Scroll-stacking projects** — sticky project cards that stack on top of one another as you scroll
- **Gallery + lightbox** — dual marquee rows of campaign creatives; click any to enlarge near-fullscreen with title & details
- **Polish** — custom cursor, magnetic buttons, count-up stats, marquee capability strip, gradient background blobs, and a working contact form (mailto)
- **Responsive** with a mobile menu and reduced-motion support

## Run locally

Just open `index.html`, or serve it:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Structure

```
index.html      # markup / all sections
styles.css      # styling, themes, and animations
script.js       # interactivity (theme toggle, reveals, roadmap, lightbox, cursor)
assets/img/     # campaign creatives and analytics imagery
```

## Tech

Hand-written HTML/CSS/JS. No dependencies. Deployed on GitHub Pages.
